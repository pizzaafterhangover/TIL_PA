# 2026-09-08 TIL — git stash로 작업 옮기기

> 이날 노트는 거의 비어 있다. 브랜치를 헷갈려 엉뚱한 곳에서 작업했을 때 git stash로 작업을 옮기는 방법 한 가지만 기록했다.

---

## 1. 브랜치를 잘못 잡고 작업했을 때

- 브랜치를 헷갈려서 다른 브랜치에서 작업했다면, `git stash`로 수정분을 임시 저장하고 → `git switch`로 올바른 브랜치로 넘어온 뒤 → `git stash pop`으로 수정분을 다시 불러올 수 있다.

```bash
git stash          # 현재 작업 임시 저장
git switch <브랜치>  # 올바른 브랜치로 이동
git stash pop      # 저장해 둔 수정분 복원
```

> 이날 Notion 노트에는 위 내용 외에 다른 학습 기록이 없어, 있는 그대로만 옮겼다. (내용이 적음)

## 오늘의 한 줄
