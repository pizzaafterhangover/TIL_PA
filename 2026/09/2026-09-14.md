## 1. Claude Code 사용법 정리

처음 써보는 도구라 공식 docs를 어느 정도 봐야 감이 잡힌다. 오늘 챙긴 포인트는 다음과 같다.

- **권한(permissions)**: 어떤 동작을 허용할지 설정하는 부분이 따로 있다. (공식 문서: `code.claude.com/docs/ko/permissions`)
- **자주 쓰는 명령어**
  - `/model claude-opus-4-8[1m]` — 모델 지정
  - `/status` — 상태 확인
- **스킬(Skill)**: AI에게 특정 능력을 미리 부여해 두는 개념. 예를 들어 "로봇 설계 기법"을 스킬로 정해두면 그 방식대로 일하게 할 수 있다. GitHub 등에서 검색해 가져올 수도 있다. (`github.com/topics/ai-skills`)
- **MCP**: 외부 기능을 쉽게 끌어다 쓰게 해주는 연결 방식.
- **토큰 절약 팁**
  - 같은 내용이라도 한글보다 영어로 지시하면 토큰을 조금이라도 아낄 수 있다.
  - PDF는 토큰 비용이 크므로 `txt`, `md` 형식을 쓰는 게 낫다.
- **사용 팁**
  - 원격 제어(remote control, `rc`) 기능은 팀 요금제에서는 안 된다.
  - `Ctrl-C`로 작업 취소, `esc`도 활용.
  - 드래그 앤 드롭으로 위치를 알려줄 수 있다.
  - 대화 용도로 Claude/Codex를 쓰는 건 추천하지 않는다고 들었다.
- 추천 조합 참고: `github.com/dietrichgebert/ponytail`

## 2. 피드백 제어의 안정성 (BIBO, 극점)

폐루프를 식으로 직접 세워보며 안정성을 공부했다. 핵심은 **BIBO 안정**(유한 입력 → 유한 출력).

목표 지점에 딱 멈추기 어려운 이유:

- 센서 노이즈
- 모터 노이즈
- 적분 오차

예를 들어 0 → 100으로 움직이는 로봇팔이 90도 근처에서 멈추거나, 90도 부근에서 일정하게 떨리는 경우가 있다. 떨려도 발산하지 않으니 **안정 상태**로는 볼 수 있지만, **정상 상태(원하는 값에 정착)**라고 보기는 어렵다.

### 극점(pole)

1차 시스템의 전달함수와 극점:

```math
G(s) = \frac{K}{\tau s + 1} \;\Rightarrow\; \text{극점 } s = -\frac{1}{\tau}
```

분모가 0이 되는 `s` 값이 곧 극점이다. 극점이 `s = a + jb`이면 응답은 오일러 공식에 따라 다음 꼴로 나타난다.

```math
e^{(a+jb)t} = e^{at}(\cos bt + j\sin bt)
```

- **실수부 `a`**: 음수면 `e^{at}`가 0으로 수렴(죽고), 양수면 발산(폭발)한다. → **감쇠 속도**를 결정.
- **허수부 `b`**: 있으면 진동하고, 클수록 빠르게 왕복한다. → **진동**을 결정.

제어 이득과의 대응:

- `Kp` 비례제어, `Ki` 적분제어, `Kd` 미분제어.
- `a`를 0에 가깝게 두면 한계 안정이 유발된다. 차로 비유하면 `a`가 커지면 가속, 작으면 감속에 해당한다.

제어 관점에서 결국 하는 일은 **원하는 위치로 극점을 옮기는 것**이고, 그게 곧 PID의 게인을 조정하는 것이다.

```math
s = -\frac{1 + K K_p}{\tau}
```

## 3. 시정수와 63.2%

1차 시스템 스텝 응답:

```math
y(t) = K\left(1 - e^{-t/\tau}\right)
```

`t = τ`일 때 `1 - 1/e ≈ 1 - 1/2.718 = 0.632`이므로 **시정수 τ에서 목표의 63.2%**에 도달한다.

| 시간 | 도달률 |
|------|--------|
| 1τ | 63.2% |
| 2τ | 86.5% |
| 3τ | 95% |
| 4τ | 98.2% |
| 5τ | 99.3% |

회로에서의 시정수도 같이 정리했다.

- RC 회로: `τ = R × C` (저항 × 커패시턴스)
- RL 회로: `τ = L / R`

## 4. 연습문제 정리

- **극점의 실수부/허수부가 결정하는 것**
  - 실수부: 감쇠 속도 (처음엔 "수렴/발산"으로 적었는데 정답은 감쇠 속도)
  - 허수부: 진동폭
- **`s = -4 ± 3j` vs `s = -1 ± 3j` 중 더 빨리 정착하는 쪽**
  - 정답: 실수부 절댓값이 큰 전자(`-4 ± 3j`). 처음엔 반대로 생각했다.
- **피드백 이득을 키울 때 불안정해질 수 있는 이유 (지연 개념)**
  - 시스템 자체의 지연으로 제어 명령이 뒤늦게 반영된다. 이 상태에서 이득을 키우면 제어 입력이 오히려 현재 시점의 오차를 증폭 → 과보정 → 발산.
- **참/거짓: 개루프로 불안정한 시스템도 피드백으로 안정하게 만들 수 있다** → 참.
