## 1. 전방 소거(row echelon) 코드

전방 소거를 미리 만들어 두었던 버전은 아래와 같다.

```py
def row_echelon(a):
    a = np.asarray(a).astype(float)
    n = len(a)
    for i in range(n):
        # 피벗 찾기
        max_row = i + np.argmax(np.abs(a[i:, i]))
        # 스왑
        a[[i, max_row]] = a[[max_row, i]]
        # 전방소거 - 해당 열의 가장 큰 값을 찾아 하위 행을 모두 0으로 만든다.
        # 부동소수점 연산 때문에 정확히 0이라기보다
        # 아주 작은 값으로 남게 된다.
        for j in range(i + 1, n):
            factor = a[j, i] / a[i, i]
            a[j, i:] -= factor * a[i, i:]
    return a
```

### 다시 보며 고치기로 한 점

- `len(a)` 대신 `a.shape`를 써서 행과 열 크기를 모두 구하기로 했다.
- 첫 for문은 열보다 행을 기준으로 돌기로 했다. 어차피 행이 열보다 적으면 가우스 소거 결과 해가 무한히 많아진다.
- 피벗이 있는 행을 기록하고, 아주 작은 피벗 때문에 생기는 `ZeroDivisionError`를 막는 코드를 넣기로 했다.
- 피벗팅이 없을 때 생기는 문제를 확인하려고, 피벗팅 동작 여부를 bool 파라미터로 받기로 했다.
- 행렬식(det) 계산에 필요한 swap 횟수를 리턴에 튜플로 함께 넘기기로 했다.

## 2. 노트북 그래픽카드 깜빡임 문제

우분투 환경에서 화면이 자주 깜빡였다. 이 노트북은 그래픽카드 하이브리드 기능을 지원한다고 하지만, 지금까지 겪어 본 바로는 리눅스 지원이 썩 좋지 못했다. 그러니 하이브리드 전환도 제대로 안 될 가능성이 크다고 봤다.

- **해결**: BIOS에 들어가 `discrete graphics` 설정으로 외장 그래픽카드만 활성화하니 문제가 사라졌다.
- `integrated`는 반대로 내장 그래픽만 쓰는 옵션이라, 외장 그래픽에 문제가 생겼을 때 쓰면 좋을 것 같다.
- `discrete`는 외장만 쓰므로 배터리 소모가 크다지만, 어차피 무거워서 들고 다니지 않고 항상 전원을 꽂아 둘 것이라 상관없다. 들고 다니기 시작하면 그때 감안하면 된다.
