## 1. 터미널/원격 접속 꿀팁

- 원격 서버에 접속해서 로컬에서 VS Code를 쓰듯이 작업할 수 있다.
- 방법: VS Code 왼쪽 아래의 **Remote** 버튼 → 명령 창에 `ssh` 명령어 입력 → VS Code Remote 서버가 다운로드될 때까지 대기 → 접속 완료.
