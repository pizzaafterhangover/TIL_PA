## 1. 첨가 행렬 만들기

튜터님은 첨가 행렬을 아래처럼 만드셨는데, 나는 `np.newaxis`로 열을 하나 늘려서 붙였다. 두 방식 모두 내부 동작이 아직 완전히 이해되지는 않았다.

```py
Ab = np.hstack([A, b.reshape(-1, 1)])
```

## 2. 가우스 소거 + 후진대입

```py
def gauss_eliminate(A, b, pivoting: bool = True, verbose: bool = False):
    """가우스 소거법 + 후진대입으로 Ax = b 를 푼다.

    Parameters
    ----------
    pivoting : True 면 부분 피벗팅을 적용한다. False 면 피벗을 그대로 쓴다
               (두 경우의 오차를 비교해야 하므로 둘 다 동작해야 한다).
    verbose  : True 면 각 소거 단계의 첨가행렬 [A|b] 를 출력한다.

    Returns
    -------
    x : 해 벡터
    steps : 단계별 첨가행렬 [A|b] 스냅샷 리스트 (초기 상태 포함)

    피벗이 0 이면 해가 유일하지 않다 -> ZeroDivisionError.
    """
    A = np.asarray(A)
    b = np.asarray(b)

    if A.ndim != 2 or b.ndim != 1:
        raise ValueError("A는 2D, b는 1D 배열이어야 함")
    if A.shape[0] != b.shape[0]:
        raise ValueError("A의 행 수와 b의 길이가 맞지 않음")

    # [A|b] 확대 행렬 생성
    b = b[:, np.newaxis]
    agumented = np.hstack((A, b))

    # 전방소거 (row_echelon)
    a, pivot_cols, n_swaps = row_echelon(agumented, pivoting)

    a = np.asarray(a, dtype=float, copy=True)
    pivot_cols = np.ndarray(pivot_cols)
    tol = 1e-12  # 아주 작은 수를 0으로 확인
    m, n = a.shape
    rank_A = rank(A)
    rank_agumented = rank(agumented)

    if rank_agumented > rank_A:
        return []  # 모순된 행렬
    if rank_agumented < n - 1:
        return []  # 무한 해

    # 후진대입
    x = np.zeros(n - 1)
    for i in reversed(range(m)):
        if (a[i] <= tol).sum() == n:  # 모두 0인 행 거르기
            continue
        x[i] = a[i, n - 1]
        for j in reversed(range(i, n - 1)):
            if i == j:
                x[i] = x[i] / a[i, j]
                continue
            else:
                x[i] = x[i] - (a[i, j] * x[j])
    return x
```

핵심 흐름은 `[A|b]` 확대 행렬을 만들고 → 전방 소거로 역사다리꼴을 만든 뒤 → 랭크를 비교해 모순/무한 해를 걸러 내고 → 후진대입으로 해를 구하는 것이다.

## 3. 구현하며 어려웠던 점

- 역사다리꼴로 소거한 뒤 마지막 $x$를 구하는 방법은 AI의 힌트를 받아 해결한 점이 아쉬웠다. 스스로 끝까지 풀어 보고 싶었다.
- 가우스-조던 소거로 역행렬을 구하는 과정에서 $[A|I] = [I|A^{-1}]$의 의미를 처음엔 이해하기 어려웠다. A와 I를 나란히 놓고 소거를 진행해서 A가 있던 자리를 I로 만들면, I가 있던 자리가 $A^{-1}$이 된다는 뜻이었다.
- 여기까지 하고 좌표 변환 공부를 시작했다.
