### Attention
• 1단계 — \(Q \cdot K^T\) (유사도 내적): 각 토큰의 쿼리 벡터와 모든 토큰의 키 벡터를 내적합니다. 내적 값이 클수록 두 토큰의 관련성이 높음을 뜻합니다.
• 2단계 — \(\div \sqrt{d_{k}}\) (스케일링): 키 벡터 차원 \(d_{k}\)의 제곱근으로 나누어, 차원이 커질 때 내적 값과 분산이 과도하게 커져 소프트맥스 기울기가 소실되는 현상을 막습니다.

```python
'''
Key k1 = [1 0] k2 = [0 1]
Value v1 = [2 0] v2=[0 3]
e^0=1
e^0.707 = 2.028
자연함수, 음수가 나와도 양수로 전환해줌, softmax에 필요
->양수로 전환하면 낮은점수와 높은점수가 더 극명해짐.
->미분하기 좋아짐


 조건 1 기본 Query 사용 q = [1 0]
1. 내적 및 스케일링 
• 1단계 — \(Q \cdot K^T\) (유사도 내적): 각 토큰의 쿼리 벡터와 모든 토큰의 키 벡터를 내적합니다. 내적 값이 클수록 두 토큰의 관련성이 높음을 뜻합니다.
• 2단계 — \(\div \sqrt{d_{k}}\) (스케일링): 키 벡터 차원 \(d_{k}\)의 제곱근으로 나누어, 차원이 커질 때 내적 값과 분산이 과도하게 커져 소프트맥스 기울기가 소실되는 현상을 막습니다.
(q*K^T/1.414)
 1. 1*1+0*0/1.414 = 0.707
 2. 1*0+0*1/1.414 = 0


2. Softmax로 가중치 계산
1/1+2.028 = 0.67
2.028/1+2.038 = 0.33
0.67 + 0.33 = 1.0

3. 최종출력
0.67 * [2 0] + 0.33 * [0 3] = [1.34 0]+[0 0.99] = [1.34 0.99]

조건 2 Query 교체 q = [0 1]
1. 내적 및 스케일링
(q*K^T/1.414)
 1. 0*1+1*0/1.414 = 0
 2. 0*0+1*1/1.414 = 0.707

2. Softmax로 가중치 계산
1/1+2.028 = 0.33
2.028/1+2.028 = 0.67
0.33+0.67=1

3. 최종출력
0.33*[2 0] + 0.67*[0 3] = [0.66 0] + [0 2.010] = [0.66 2.01]

조건 3 두번째 Key 차단 (q=[1 0], 두번째 위치 mask)

1. 내적 및 스케일링
(q*K^T/1.414)
 1. (1*1+0*0)/1.414 = 0.707
 2. (1*0+0*1)/1.414 = 0

1-1. 마스킹 (softmax 전에 적용)
 차단할 위치의 점수를 -∞ 로 바꿈
 1. 0.707      (유지)
 2. 0 → -∞     (차단)

2. Softmax로 가중치 계산
e^0.707 = 2.028
e^-∞   = 0
 1. 2.028/(2.028+0) = 1.0
 2. 0/(2.028+0)     = 0.0
 1.0 + 0.0 = 1.0

3. 최종출력
1.0*[2 0] + 0.0*[0 3] = [2 0] + [0 0] = [2 0]
'''

import numpy as np

K = np.array([[1.0, 0.0],[0.0, 1.0]])
V = np.array([[2.0, 0.0],[0.0,4.0]])

def softmax(x):
    e_X=np.exp(x-np.max(x)) # 최대값 오버플로우 방지
    return e_X/np.sum(e_X)

def compute_attention(q,K,V, mask=None):    
    d_k=K.shape[-1]
    scores=(q@K.T)/np.sqrt(d_k)

    if mask is not None:
        scores = np.where(mask, -np.inf, scores)

    weights = softmax(scores)

    output = weights @ V
    return weights, output

conditions = [
    ("Q1=",np.array([1.0, 0.0]),None),
    ("Q2=",np.array([0.0, 1.0]), None),
    ("Q3=",np.array([1.0, 0.0]), np.array([False, True]))
    ]

for title, q, mask in conditions:
    weights, output = compute_attention(q,K,V,mask)
    print(title)
    print(q)
    print(np.round(weights, 4),np.round(weights,3))
    print(np.sum(weights))
    print(np.round(output,4))
```
