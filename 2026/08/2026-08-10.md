## 3. 변수와 상수, 스코프

- `const`: 초기화 후 값을 바꿀 수 없는 상수.
- `constexpr`: 컴파일 타임에 값이 정해지는 상수.
- `auto`: 초기화값으로부터 타입을 자동 추론.

```cpp
const double pi = 3.14159;       // 초기화 후 변경 불가
constexpr int max_value = 100;   // 컴파일 타임 상수
auto name = "Hello, C++17!";     // 타입 자동 추론
```

전역/지역 변수와 스코프 해석 연산자 `::`:

```cpp
int number = 42;             // 전역 변수
int main() {
    int number = 10;         // 지역 변수
    std::cout << ::number;   // 전역 변수 접근 (42)
    std::cout << number;     // 지역 변수 (10)
    { int number = 5; }      // 블록 스코프 (5)
}
```

범위 기반 for문:

```cpp
for (int i : readings) {
    std::cout << "Reading: " << i << std::endl;
}
```

## 4. 실습 — 계산기 만들기

`+ - * / %` 연산을 함수로 분리하고, 입력 검증(`std::cin.fail()` 처리)과 `switch` 분기로 처리하는 콘솔 계산기를 작성했다. 0으로 나누기 같은 예외는 `std::cerr`로 안내한다.

```cpp
int divide(int a, int b) {
    if (b == 0) {
        std::cerr << "오류: 0으로 나눌 수 없습니다!" << std::endl;
        return 0;
    }
    return a / b;
}

int input_number() {
    int num;
    std::cin >> num;
    while (true) {
        if (std::cin.fail()) {
            std::cin.clear();  // 에러 플래그 해제
            std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
            std::cout << "잘못된 입력입니다. 숫자를 입력하세요: ";
        } else {
            break;
        }
    }
    return num;
}
```

다음 과제로 **스택–힙 메모리 관리**가 남았다.

## 5. C++ 팁

- 값을 변수에 다시 저장한 뒤 출력하는 습관을 들이자.
- `std::`는 "standard"의 약자. `using namespace std;`로 생략할 수 있지만, 보통은 명시적으로 `std::`를 쓰는 편이 낫다.

## 6. 특강 — GitHub·링크드인 관리 요령 (강창민)

면접관이 가장 중요하게 보는 것은 **꾸준함**. 퍼스널 브랜딩은 결국 스스로를 알리는 방법이다.

**GitHub에서 보는 것**:

- 핀(pin) 레포와 README를 꼼꼼히 본다. 커밋 히스토리도 확인한다.
- 스타·팔로워 수는 신입 평가 기준이 아니다.
- 핀 레포는 지금부터 관리해야 하며, 커밋 메시지는 누구나 본다는 걸 항상 기억할 것.

**핀 레포에 담을 것**:

- 실행 가능성·배포 가능성·확장 가능성, 직무 연관성, 스토리(문제 정의 → 해결 과정 → 결과).
- README는 코드보다 먼저 읽히는 **프로젝트의 얼굴**이고, 노력 대비 효과가 크다. 무엇을·왜, 데모/스크린샷, 기술적 의사결정, 결과·성과, 실행 방법을 담자.
- 자연스럽게 쓰려면 스스로 생각할 시간이 필요하다(하루 30분 이상).

**이력서**: 하이라이트만. 면접에서 꼭 전달할 키워드는 2~3개만 잡고, 면접은 자연스럽고 편하게.

**문서화 항목**: 트러블슈팅, 기술적 의사결정, 위키 회고, 이슈·PR, 아키텍처 다이어그램.

**링크드인**: 가입이라도 해두면 좋다. 공부할 때는 마인드맵과 메타인지를 활용하자.
