# 2026-08-25 TIL — SSH 원격 접속·가상 센서(udev)·turtlesim

> 과제 리뷰를 따라 하며 로봇 개발 환경을 직접 만져봤다. SSH 키 기반 접속과 헤드리스 운용, loop 디바이스와 udev 규칙으로 '가짜 센서'를 만들어 고정 장치명을 붙이는 법, 그리고 turtlesim으로 넘어가 제동 거리 계산 코드까지 손에 익힌 하루였다.

---

## 1. SSH 원격 접속

### 암호키 생성과 복사

```bash
ssh-keygen -t ed25519         # 키 생성
ssh-copy-id name@hostip       # 공개키를 원격 호스트에 복사
```

### 헤드리스 운용

모니터 없이 명령만 원격으로 던지거나 파일을 주고받는다.

```bash
ssh "계정"@hostip '명령어'                 # 명령만 원격으로 실행
scp "파일명" "계정"@hostip:/"위치"         # 원격으로 파일 복사
```

## 2. 가상 USB 하드웨어(가짜 센서) 만들기

실제 센서 없이도 개발할 수 있도록, 이미지 파일을 loop 디바이스로 올리고 udev 규칙으로 고정 장치명을 붙였다.

```bash
# 1) 센서 이미지 파일 생성 (truncate로 용량만 잡아둠)
mkdir -p ~/fake_sensors && cd ~/fake_sensors
truncate -s 10M lidar.img imu.img

# 2) loop 디바이스로 연결 → /dev/loop# 이 할당됨
sudo losetup -f --show lidar.img
sudo losetup -f --show imu.img
```

이후 `/etc/udev/rules.d/99-robot-sensor.rules` 에 규칙을 등록한다. `SUBSYSTEM`, `KERNEL`, `ATTR{...}`, `SYMLINK+=`, `MODE`, `GROUP` 등으로 조건과 별칭을 지정한다.

```
# 라이다
KERNEL=="loop*", SUBSYSTEM=="block", ATTR{diskseq}=="51", SYMLINK+="robot_lidar", MODE="0666"
ATTR{loop/backing_file}=="*/lidar.img",
# IMU
KERNEL=="loop*", SUBSYSTEM=="block", ATTR{diskseq}=="53", SYMLINK+="robot_imu", MODE="0666"
```

규칙을 재적용하고 확인한다.

```bash
sudo udevadm control --reload-rules && sudo udevadm trigger
ls -l /dev/robot_*

# loop 할당 해제
sudo losetup -d /dev/loop21

# 어떤 이미지가 어느 loop에 마운트됐는지 확인
cat /sys/devices/virtual/block/loop21/loop/backing_file
cat /sys/devices/virtual/block/loop22/loop/backing_file
```

이렇게 하면 `/dev/robot_lidar`, `/dev/robot_imu` 처럼 매번 바뀌지 않는 이름으로 센서를 참조할 수 있다.

## 3. turtlesim 패키지와 제동 거리 계산

turtlesim 과제로 넘어가며 제동(정지) 거리 계산 코드를 작성했다. 물리적으로는 바퀴와 바닥 사이 마찰이 유일한 제동력이라고 보면, 감속도는 $a = \mu g$ 이고 운동에너지 $\tfrac{1}{2}mv^2$ 가 마찰일 $\mu m g d$ 로 모두 소모되어 정지하므로 제동 거리는 다음과 같다.

$$
d = \frac{v^2}{2\mu g}
$$

```cpp
// stop_distance.cpp — 로봇의 제동(정지) 거리 계산
//   감속도 a = mu * g   (mu: 마찰계수, g: 중력가속도)
//   d = v^2 / (2 * mu * g)
// 빌드: g++ -Wall -std=c++17 stop_distance.cpp -o stop_distance
// 실행: ./stop_distance <속도[m/s]> <마찰계수>
//   인자를 안 주면 값을 직접 입력받는다.
```

과제 진행 메모:
- 하나는 `echo` 로, 다른 하나는 subscriber로 토픽을 확인한다.
- 2-4까지는 필수 실행, 2-5~9는 선택 과제, 2-10까지 이어진다.
