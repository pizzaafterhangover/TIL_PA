## 1. row_echelon — 전방 소거로 사다리꼴 만들기

부분 피벗팅(절댓값이 가장 큰 행을 피벗으로)을 적용해 전방 소거를 수행한다.

```py
def row_echelon(a):
    a = np.asarray(a).astype(float)
    n = len(a)
    for i in range(n):
        # 피벗 찾기: 해당 열에서 절댓값이 가장 큰 행
        max_row = i + np.argmax(np.abs(a[i:, i]))
        # 스왑
        a[[i, max_row]] = a[[max_row, i]]
        # 전방 소거: 하위 행을 모두 0으로 만든다.
        # 단, 부동소수점 연산 탓에 완전한 0이 아니라
        # 아주 작은 값으로 남게 된다.
        for j in range(i + 1, n):
            factor = a[j, i] / a[i, i]
            a[j, i:] -= factor * a[i, i:]
    return a
```

- `np.argmax` 는 가장 큰 값의 인덱스를 돌려준다.

## 2. rank — 0이 아닌 행 세기

전방 소거 후, 모든 원소가 (사실상) 0인 행을 빼고 남은 행의 개수를 센다. 부동소수점 때문에 완전한 0 대신 아주 작은 값과 비교하는 허용 오차(`tol`)를 둔다.

```py
def rank(a):
    a = row_echelon(a)
    tol = 1e-12                      # 이보다 작으면 0으로 간주
    conditions = np.all(a < tol, axis=1)
    count = np.sum(conditions)       # 모든 열이 0(아주 작은 값)인 행의 개수
    return len(a) - count
```

## 3. 축별 회전행렬

```py
def rot_x(theta: float) -> np.ndarray:
    c, s = np.cos(theta), np.sin(theta)
    return np.array([[1, 0, 0],
                     [0, c, -s],
                     [0, s,  c]])

def rot_y(theta: float) -> np.ndarray:
    c, s = np.cos(theta), np.sin(theta)
    return np.array([[ c, 0, s],
                     [ 0, 1, 0],
                     [-s, 0, c]])

def rot_z(theta: float) -> np.ndarray:
    c, s = np.cos(theta), np.sin(theta)
    return np.array([[c, -s, 0],
                     [s,  c, 0],
                     [0,  0, 1]])
```

## 4. 직교성 확인 시 주의할 점

행렬의 직교성을 확인할 때는 행렬식이 $-1$ 이 되는 경우(정확히는 $\det = -1$ 인 반사)를 따로 걸러야 한다.

- 단순히 "반사가 일어났다"로 끝나는 게 아니라, 부피 개념으로 보면 음(−)의 부피가 되는 상황이다.
- 로봇공학에서는 이것이 로봇이 자기 몸 안쪽으로 파고드는, 말이 안 되는 구동을 요구하는 꼴이 될 수 있다. 그래서 회전은 $\det = +1$ 인 직교행렬이어야 한다.
